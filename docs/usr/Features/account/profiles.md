Profiles let several people, or several moods, share one install. Each profile has its **own**:

- library: likes, dislikes, playlists, bookmarks, follows, your edits;
- history and statistics;
- downloads;
- settings, including theme, language and fonts;
- YouTube Music and OpenSubsonic sign-ins.

## Managing profiles

**Account → Switch profile** lists your profiles with when each was last used.

- **Search or add**: type a name to find a profile, or add a new one.
- Tap a profile to **switch** to it. Playback stops, the app loads the profile and the local scan
  runs again with its settings.
- Profiles can be deleted.

## The default profile

Some things are shared by every profile, so only the **default profile** can change them:

- the song cache, downloads and image cache sizes, and clearing them
  ([Storage](../offline/storage.md));
- [backup and restore](../backup/backup-and-restore.md).

Those rows say *Shared by every profile, only Default can change it* in other profiles.

## Account page

The profile button opens **Account**: History, Statistics, Liked, Disliked, Downloaded and Switch
profile.
