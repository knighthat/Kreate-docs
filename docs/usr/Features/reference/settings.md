| Section | Settings |
|---------|----------|

### Configure YouTube Music

Use YouTube Music account, Sign in / channel, Sync songs / albums / artists / playlists, Region,
quality On Wi-Fi / On mobile data, Login for playback, Proxy.
See [YouTube Music](../sources/youtube-music.md).

### Configure OpenSubsonic

Main switch, Sign in (server address, password or API key), Allow self-signed certificate, Server
library sync, Direct play, quality On Wi-Fi / On mobile data, ReplayGain reference, Proxy.
See [OpenSubsonic servers](../sources/opensubsonic.md).
