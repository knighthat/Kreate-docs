Kreate is written and maintained by [knighthat](https://github.com/knighthat). This page thanks the people
and projects that help along the way.

## 🌱 Where Kreate comes from

Kreate v1 and v2 started as a fork of [RiMusic](https://github.com/fast4x/RiMusic) by fast4x,
which itself is a fork of [ViMusic](https://github.com/vfsfitvnm/ViMusic) by vfsfitvnm.
Those versions were built on their work, and Kreate wouldn't be here without it.

Kreate v3 is a complete rewrite from scratch. It isn't forked from any project and shares no code with them.
Though, v3 supports many exports from previous versions.

## 🌍 Translators

Kreate and this website are translated by volunteers on [Crowdin](https://translate.kreate.knighthat.me).
See everyone who helped on the [Translators](/translators) page.
